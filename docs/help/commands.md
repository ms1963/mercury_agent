# Slash commands

Commands work in the CLI REPL, the web chat and every chat platform.

| Command | Effect |
|---|---|
| /new, /reset | Start a fresh session |
| /model [provider/model] | Show or switch the model for this session |
| /pattern [name] | Reasoning pattern (react, plan-execute, reflexion, …) |
| /personality [name] | Switch persona |
| /retry | Re-run the last user message |
| /undo | Remove the last exchange |
| /stop | Abort the running agent |
| /compress | Summarise the session to save context |
| /usage | Token and cost usage |
| /insights | Usage insights over 30 days |
| /skills | List skills |
| /rollback [n] | Restore a file checkpoint |
| /approve, /deny [id] | Resolve pending tool approvals |
| /memory, /feedback, /debug, /tools, /sessions | Inspect state |
| /help [topic] | This help |
