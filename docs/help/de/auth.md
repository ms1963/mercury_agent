# Konten & Tokens

- Der erste registrierte Benutzer wird zum **Administrator**. Weitere Registrierungen können mit `auth.allowRegistration: false` deaktiviert werden.
- `mercury user list|add|passwd|role|delete` (Administrator)
- `mercury token create <name> --scopes chat,mcp` — Scopes schränken ein, was ein API-Client tun darf.
- Web-UI → Account & tokens.
