# Slash-Befehle

Befehle funktionieren in der CLI-REPL, im Web-Chat und auf jeder Chat-Plattform.

| Befehl | Wirkung |
|---|---|
| /new, /reset | Eine neue Sitzung starten |
| /model [provider/model] | Modell dieser Sitzung anzeigen oder wechseln |
| /pattern [name] | Denkmuster (react, plan-execute, reflexion, …) |
| /personality [name] | Persona wechseln |
| /retry | Die letzte Benutzernachricht erneut ausführen |
| /undo | Den letzten Austausch entfernen |
| /stop | Den laufenden Agenten abbrechen |
| /compress | Die Sitzung zusammenfassen, um Kontext zu sparen |
| /usage | Token- und Kostennutzung |
| /insights | Nutzungseinblicke über 30 Tage |
| /skills | Skills auflisten |
| /rollback [n] | Einen Datei-Checkpoint wiederherstellen |
| /approve, /deny [id] | Ausstehende Tool-Freigaben auflösen |
| /memory, /feedback, /debug, /tools, /sessions | Zustand untersuchen |
| /help [topic] | Diese Hilfe |
