# Mercury erweitern

- **Polyglott-Tool**: `mercury new tool <name> --lang python|js|go|cpp|java`
- **Skill**: `mercury new skill <name>`
- **Workflow**: `mercury new workflow <name>`
- **Plattform-Adapter**: `mercury new adapter <name>` (TypeScript-Klasse, die `BaseAdapter` erweitert)
- **Plugin**: `mercury new plugin <name>` — Registrieren Sie Tools, Hooks, LLM-Provider, Workflow-Vorlagen und Befehle.
Siehe docs/EXTENDING.md im Repository.
